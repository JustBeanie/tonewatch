## Goal
The repo is now **public**. Nothing tracked may reference the legacy product this project was modelled on. That means its full name in any spacing or case (`the legacy notifier`, `the legacy notifier`, `the legacy notifier`, `legacy-notifier install`, …) and its abbreviation `legacy tones.cfg`/`tones-cfg`, wherever that abbreviation identifies the product. The importer keeps working, but it is described generically as an importer for **legacy `tones.cfg` two-tone configuration files**.

Generic radio terms stay: "two-tone", "two-tone sequential paging", "long tone", "tone set". Only the product name and its abbreviation go.
