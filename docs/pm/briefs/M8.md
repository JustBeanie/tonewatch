## Goal
Ship ToneWatch as one hardened multi-arch container image (amd64 + arm64). The same image is used by plain Docker and, later, the HA add-on (M10). ## Required
1. **The backend already serves the SPA** (done in W1b, via `settings.web_root`). The image must place the built web assets where `web_root` expects them (`<package>/web_dist`), and the container e2e reuses the W1b Playwright specs unchanged.
2. **M8.1 `docker/Dockerfile`**, multi-stage, with every base image pinned by digest (`@sha256`, taken from `docker buildx imagetools inspect` in CI, or from registry docs; never invented, so mark `TODO(pin-digest)` only if it can't be verified):
   - **`web` stage:** `node:24-slim`, pnpm via corepack pinned to the `packageManager` version, `pnpm install --frozen-lockfile`, `pnpm build`.
   - **`builder` stage:** `python:3.13-slim` + `uv` (copied from the pinned `ghcr.io/astral-sh/uv` image). Run `uv sync --frozen --no-dev` into `/opt/venv`, with **no build tools left in the final image**.
   - **`runtime` stage:** `python:3.13-slim` with `libportaudio2`, `rtl-sdr`, `tini` and `ca-certificates` via `apt-get install --no-install-recommends` with lists removed.
     - A non-root `tonewatch` user (fixed UID/GID 10001) in the `audio` and `plugdev` groups.
     - Copy the venv and web dist in.
     - `ENV TONEWATCH_DATA_DIR=/data TONEWATCH_BIND_HOST=0.0.0.0 TONEWATCH_BIND_PORT=8099`.
     - `VOLUME /data`, `EXPOSE 8099`, `USER tonewatch`, `ENTRYPOINT ["tini","--","tonewatch"]`, `CMD ["serve"]`.
     - **`HEALTHCHECK`:** a small Python one-liner hitting `/healthz` (no curl in the image).
   - **OCI labels:** source, revision, version, licenses=MIT.
   - `.dockerignore` excludes `.git`, `.tools`, `.venv`, `node_modules`, `data`, coverage, and `docs/pm/runs`.
   - **Size budget:** under 350 MB uncompressed for amd64, asserted in CI.
3. **M8.2 `docker/compose.*.yml`**, one per source type:
   - **soundcard:** `devices: ["/dev/snd:/dev/snd"]`, `group_add: [audio]`
   - **stream:** no devices
   - **rtlsdr:** `devices: ["/dev/bus/usb:/dev/bus/usb"]`, plus a comment explaining the host `dvb_usb_rtl28xxu` blacklist
   - **All three share a hardened base** via YAML anchors or `extends`, delivering S5 hardening early:
     - `read_only: true` with `tmpfs: [/tmp]`
     - `cap_drop: [ALL]`
     - `security_opt: ["no-new-privileges:true"]`
     - a named `/data` volume, `restart: unless-stopped`, and a healthcheck
   - **Document the known device-access caveat:** whether `/dev/snd` and USB work with `cap_drop: ALL` and a non-root user in the `audio`/`plugdev` groups. Mark it as needing hardware verification (the PM keeps a HIL checklist). Don't claim it works.
   - Replace the `just docker-build` and `just compose-up source=` placeholder recipes with real ones that fail clearly when Docker isn't installed.
4. **M8.3 CI and release.**
   - **`.github/workflows/docker.yml`:**
     - On PR and push to main: buildx build amd64 + arm64 with QEMU, **no push**, and a size assertion.
     - `trivy image` on the built amd64 image, failing on HIGH/CRITICAL with a fix available.
     - **Container smoke test:** run the image with a generated stream-free file source config mounted read-only into `/data`, wait for `/readyz`, fetch `/`, `/api/auth/status` and `/healthz`, then confirm the container runs as UID 10001 (`docker exec id -u`) with a read-only root fs.
     - **Run the Playwright e2e against the container**, reusing the M6b specs with `TONEWATCH_E2E_URL`.
   - **`.github/workflows/release.yml`:**
     - release-please (manifest config for the `backend` Python package version).
     - On a published release, push to GHCR `ghcr.io/justbeanie/tonewatch:{X.Y.Z,X.Y,latest}`.
     - **cosign keyless signing** (OIDC, `id-token: write` scoped to that job only).
     - SBOM with syft (`spdx-json`) attached as an attestation.
     - `actions/attest-build-provenance`.
   - **Least-privilege permissions per job:** `packages: write` only on the push job; everything else `contents: read`.
   - **Private repo:** GHCR pushes work, but the public attestation UI may not. Document that.
   - All actions pinned by SHA (resolve with `git ls-remote`). `zizmor` must be clean.
   - Add the image to `THIRD_PARTY_NOTICES.md` (Debian packages: note that `rtl-sdr` is GPL-2.0 and is a separate executable invoked as a subprocess, not linked, with the notice included). Make sure `scripts/license_check.py` policy text reflects that bundled GPL **executables** are allowed as separate programs while GPL **libraries linked into the app** are not. Update the docstring and `docs/decisions/0004-container-licensing.md`. **Don't** weaken the Python/web dependency check.
