## Goal
Add a `tonewatch/` add-on that is a **manifest only**, pointing at the published multi-arch image `ghcr.io/justbeanie/tonewatch`. Follow the existing `bacnet_mqtt_gateway/` pattern exactly: manifest tests, a linter compatibility copy, and anonymous image resolution.

Before starting, read:
- `ha-addons/bacnet_mqtt_gateway/{config.yaml,DOCS.md,README.md,tests/}` and `ha-addons/.github/workflows/bacnet-mqtt-gateway.yml`

## Required
1. **`tonewatch/config.yaml`:**
   - **Identity:** `name: ToneWatch`, `slug: tonewatch`, `version` equal to the tonewatch release it targets, `url`, `stage: experimental`, `arch: [aarch64, amd64]`.
   - **Image:** `image: "ghcr.io/justbeanie/tonewatch"` with **no `{arch}`**, because the image is one multi-arch index. Explain that in a comment, as bacnet does for its per-arch images.
   - **Runtime:** `init: false` (the image uses tini), `ingress: true`, `ingress_port: 8099` (the image's port; PLAN's 8080 predates the image), `panel_icon: mdi:fire-truck`, `panel_title: ToneWatch`.
   - **Devices and services:**
     - `audio: true` and `usb: true`, following ADR 0009's audio decision
     - `map`: `media` read-write
     - `services: ["mqtt:want"]`, `discovery: [tonewatch]`
   - **Backup:** **hot** (omit `backup:`) with `backup_pre: tonewatch db checkpoint`. Never `backup: cold`, which would stop a paging monitor on every nightly backup.
   - **`options`/`schema`:** exactly M10a's keys: `log_level`, `public_base_url`, `mqtt_mode`, `ui_password` (`password?`).
   - **Linter hygiene:** don't restate defaults the linter rejects, as the bacnet comments explain.
2. **`tonewatch/DOCS.md`, `README.md`, `CHANGELOG.md`, `translations/en.yaml`** (option names and descriptions), plus `icon.png` (256×256) and `logo.png`. Generate simple, original PNGs with a script you keep out of the repo; don't use third-party artwork.
   - DOCS covers: ingress, MQTT via Supervisor, `public_base_url`, recordings under Media → tonewatch, backups, audio/SDR device notes from ADR 0009, and the "supplemental notification tool, not a certified primary alerting system" disclaimer.
3. **`tonewatch/tests/`**, stdlib `unittest` + PyYAML like bacnet, asserting:
   - the image has no `{arch}`
   - `ingress_port == 8099`
   - options and schema keys match exactly and the translation keys cover them
   - `backup_pre` is the checkpoint command
   - no `backup: cold`
4. **`.github/workflows/tonewatch.yml`**, a copy of the bacnet workflow structure:
   - **Triggers and permissions:** path filters, `permissions: contents: read`, `timeout-minutes` on every job, and actions pinned to the **same** SHAs the bacnet workflow uses.
   - **Jobs:**
     - `manifest`
     - `lint` (`frenck/action-addon-linter`, with the compatibility copy only if a key needs it)
     - `image`: resolve `ghcr.io/justbeanie/tonewatch:<version>` anonymously. Don't split per arch; instead assert the manifest index contains `linux/amd64` and `linux/arm64`.
   - The `image` job **will fail until a tonewatch release is published and the GHCR package is public**. Both are user decisions: the release-please repo setting, and the repo going public at v1.0. Don't skip, gate or soften it; state it in your final message as the known red job.
