# Vendored SAMM model data

This directory contains the SAMM v2 question, stream, and answer-option data
used by the validator. It is derived from
`owaspsamm/core` commit `f4ed4a13289db54499cb412ec4846ea12e747ac8` under the
repository's `license.txt`: Creative Commons Attribution-ShareAlike 4.0
International (CC BY-SA 4.0),
<https://creativecommons.org/licenses/by-sa/4.0/>.

The aggregate file is a mechanical, attributed extraction of the official
model data; no question or answer wording was rewritten.
