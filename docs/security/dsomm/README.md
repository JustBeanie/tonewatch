# OWASP DSOMM baseline

Activity definitions come from the official
`devsecopsmaturitymodel/DevSecOps-MaturityModel-data` repository, pinned to
commit `46170cad1cda53d14c0c61061f7e7e4bd62c0928`.

Source model URL:
<https://raw.githubusercontent.com/devsecopsmaturitymodel/DevSecOps-MaturityModel-data/46170cad1cda53d14c0c61061f7e7e4bd62c0928/generated/model.yaml>
(model version 4.3.1, released 2026-06-05). This baseline includes every
official activity at levels 1 and 2, across every dimension present in that
model, including Agentic AI. S2 pipeline controls are intentionally not
included here.
