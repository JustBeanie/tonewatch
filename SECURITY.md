# Security policy

## Supported versions

Only the latest release of ToneWatch receives security fixes. Upgrade to the
newest release before reporting a problem.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/JustBeanie/tonewatch/security/advisories/new).
Do not open a public issue or pull request for a security problem, and do not
include radio recordings, API tokens or other secrets in any report.

Please include:

- the ToneWatch version and how it is deployed (Docker, Windows zip, source);
- the steps to reproduce, and what an attacker gains;
- any proof-of-concept, with secrets and recordings removed.

## What to expect

- Acknowledgement within 7 days.
- An assessment and a planned fix date within 14 days.
- A fixed release and a published GitHub Security Advisory, crediting you
  unless you ask not to be named. Please keep the details private until the
  advisory is published, or for 90 days after your report, whichever is first.
